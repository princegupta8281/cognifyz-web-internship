# Cognifyz Technologies — Web Development Internship Project (React + Vite + Tailwind CSS)

This project implements all **Level 1, Level 2, and Level 3** tasks from the **Cognifyz Technologies Web Development Internship** program.

## Prerequisites
- **Node.js** (v18+ recommended) — Download from https://nodejs.org

## How to Run Locally (Step-by-Step)
1. Extract the ZIP archive and open the `cognifyz-web-internship` folder in VS Code or your terminal.
2. Install project dependencies:
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```
4. Open the local URL displayed in your terminal (usually `http://localhost:5173`) in your browser.
